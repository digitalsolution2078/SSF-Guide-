# Contributing to SSF Guide

Thanks for helping keep this guide accurate and useful!

## How to Contribute

1. **Fork** the repository and create a branch for your change.
2. Make your edits in Markdown (keep the existing chapter structure in `docs/`).
3. Open a **pull request** describing what you changed and why.

## Content Guidelines

- **Cite the source** for any rates, limits, or legal provisions — link to the SSF website, the Act/Regulation, or an official notice, and mention the date.
- Figures change over time (benefit ceilings, tax caps, directives). When updating a number, note the effective date if known.
- Keep language simple and practical — this guide is for employers and employees, not lawyers.
- Nepali terms are welcome alongside English (e.g., *listing / सूचीकरण*).

## Reporting Issues

Spotted outdated or incorrect information? Open a GitHub issue with:

- The file and section concerned
- What is wrong or outdated
- A link to the correct/official information if you have one
